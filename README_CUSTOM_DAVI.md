# 🤖 Takeshi Bot — Davi Rian Custom Edition

> **Engine de Automação de WhatsApp e Atendimento Inteligente**  
> Baseado no projeto open-source Takeshi Bot (Baileys/Node.js), profundamente modificado, enriquecido e otimizado por **Davi Rian** (@daviriann / @davirian-dev).

---

## ⚡ Melhorias e Módulos Criados por Davi Rian:

1. **Automação de Pagamentos Pix (Comandos Rápidos)**:
   - `!pix10` e `!pix69`: Geração e envio de chaves Pix automáticas para liberação imediata de acessos e planos.
2. **Triagem & Moderação Automática de Membros**:
   - `!triagem`: Fluxo de boas-vindas, formulário de entrada e triagem de segurança para novos participantes de grupos.
   - `!aprovar`: Validação e aprovação de novos membros moderados pelo administrador.
   - `!membros`: Listagem e estatísticas da base de assinantes e comunidade.
3. **Gestão de Planos & Entregáveis Digitais**:
   - `!planos`: Catálogo de assinaturas, planos VIP e pacotes de acesso.
   - `!vip`: Link e instruções de acesso ao canal restrito VIP.
   - `!ebooks`: Entrega de materiais digitais e guias automatizados.
   - `!regras`: Fixação e envio das regras de conduta dos grupos.
4. **Integração com o Ecossistema Davi Bot**:
   - Conexão como serviço de mensageria para disparos automáticos orquestrados pelo **Davi Bot** (FastAPI).
   - Suporte a geração de roteiros (`!roteiro`) e legendas automáticas (`!legenda`).

---

## 🚀 Como Iniciar:
```bash
npm install
npm start
```
Escaneie o QR Code no terminal ou utilize a sessão autenticada para ativar o bot.
